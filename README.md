## About

Full-stack developer with a backend focus, based in Bangladesh. I build APIs and backend services with Node.js, Express and MongoDB, web apps with React and Next.js, and mobile apps with React Native and Expo, mostly in TypeScript.

Lately I've been publishing small open-source tools and CLIs, and contributing fixes upstream.
